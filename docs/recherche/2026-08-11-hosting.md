# Recherche: Gratis-Hosting Angular + .NET-API + DB — Stand 11.08.2026

> Claude-Recherche vom 11.08.2026 für das Projekt CV-Website (Repo ce451/my-cv).
> Arbeitsdokument. Quellen jeweils verlinkt; unverifizierte Punkte am Ende gelistet.

**TL;DR — die 5 wichtigsten Befunde:**
1. **Oracle Cloud Always Free wurde am 15.06.2026 stillschweigend halbiert** (Ampere A1: 4→2 OCPU, 24→12 GB RAM), ab 18.08.2026 beginnt die Durchsetzung. [Quelle](https://docs.oracle.com/en-us/iaas/Content/FreeTier/freetier_topic-Always_Free_Resources.htm)
2. **Azure App Service F1 unterstützt keine Custom Domain** (erst ab Basic/B1) — K.-o.-Kriterium für "eigene Domain".
3. **Kein geprüfter Free-Container-Host bietet persistenten beschreibbaren Storage** (Render, Koyeb, Railway, Fly: ephemeres Dateisystem bzw. kein Free-Tier) — eine SQLite-Datei überlebt dort keinen Neustart. Praktikabel nur: read-only-SQLite im Docker-Image, externe Managed-DB, oder Self-Host.
4. **Cloudflare Workers kann kein echtes .NET** (nur experimenteller WASM-Hack). "Cloudflare Containers" ist seit 13.04.2026 GA, aber **nur im 5$/Monat-Paid-Plan**.
5. Netlify hat am 04.09.2025 auf ein Credit-System umgestellt (effektiv ~15 GB statt 100 GB), für eine CV-Seite ausreichend. Vercel Hobby bleibt strikt auf **nicht-kommerzielle** Nutzung beschränkt.

Nebenbefund: Aktuelle .NET-LTS ist **.NET 10** (seit 11.11.2025, Support bis 14.11.2028) — [dotnet.microsoft.com](https://dotnet.microsoft.com/en-us/platform/support/policy/dotnet-core). **.NET 8 und .NET 9 laufen beide am 10.11.2026 aus.** Aktuelle Angular-Hauptversion: **v22**, Build-Time-Prerendering/SSG via `outputMode: "static"` — [angular.dev/guide/ssr](https://angular.dev/guide/ssr).

### A4 — Self-Host via Cloudflare Tunnel

- Kostenlos (cloudflared + Zero Trust Free) — [Cloudflare One](https://developers.cloudflare.com/cloudflare-one/)
- Versteckt Heim-IP: nur ausgehende Verbindungen, Origin nicht scannbar — [FAQ](https://developers.cloudflare.com/cloudflare-one/faq/cloudflare-tunnels-faq/)
- Kein Port-Forwarding nötig (4 ausgehende QUIC-Verbindungen) — [Connect Networks](https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/)
- Voraussetzung: Domain-DNS bei Cloudflare (Free-Plan reicht)
- TLS automatisch (Universal SSL); Zertifikat deckt Root + 1 Subdomain-Ebene
- ToS-seitig für kleine JSON-APIs unkritisch — [Updated ToS](https://blog.cloudflare.com/updated-tos)

### A5 — GitHub Actions CI/CD

- Public Repo: **unlimitiert gratis** — [Billing-Doku](https://docs.github.com/en/billing/concepts/product-billing/github-actions)

Zusatzkosten überall: Domain-Registrierung ~10-15 EUR/Jahr, bei keinem Anbieter inkludiert.

## B) Empfohlene Architekturen

### (i) Rein statisch, kein Backend
Angular SSG auf **Cloudflare Pages** (Alternative: GitHub Pages) + eigene Domain. Kontakt per `mailto:`. Kein Cold-Start, kein Policy-Risiko, kein Wartungsaufwand. Cloudflare Pages: großzügigstes Bandbreiten-Limit aller Static Hosts, keine Kommerz-Einschränkung. **Kosten: 0 EUR + Domain.**

### (ii) Statisch + kleine öffentliche API
Frontend wie (i). Backend: **Render Free** (Docker, .NET 10, Custom Domain gratis, keine Kreditkarte) — einziger geprüfter Container-Host ohne Kreditkartenpflicht mit erhaltenem Free-Tier. DB extern: **Neon** oder **Turso** (kein persistenter Storage auf Render). 15-Min-Spin-down mit 30-60s Cold Start tolerierbar; täglicher GH-Actions-Cron-Ping hält wach. Azure SWA Managed Functions wäre eleganter, ist aber nur bis .NET 8 (EOL 11/2026) dokumentiert — nicht empfohlen. **Kosten: 0 EUR + Domain.**

### (iii) Hybrid: statisches Frontend Cloud + privates Backend self-hosted
Frontend wie (i). Backend: eigener Server/NAS mit .NET-10-API + echter SQLite-Datei, bei Bedarf exponiert via **Cloudflare Tunnel**. Einzige Variante mit echtem persistentem Storage ohne externe Managed-DB. Kein Cold-Start, kein Policy-Risiko. Nachteil: Verfügbarkeit hängt am Heimnetz, Absicherung liegt bei dir. **Kosten: 0 EUR + Domain.**
